# 🏥 Emergency Room Data Analysis Dashboard – Excel

## 📊 Project Overview

This project focuses on analyzing Emergency Room operations using Microsoft Excel.

The objective is to transform raw hospital emergency room data into meaningful business insights that can help hospital management understand patient flow, waiting times, admission patterns, department referrals, gender distribution, and overall emergency room performance.

An interactive Excel dashboard was developed using Power Query, Power Pivot, DAX, Pivot Tables, Pivot Charts, and data visualization techniques.

---

## 🎯 Business Objective

The main objective of this project is to answer important Emergency Room operational questions such as:

- How many patients visited the Emergency Room?
- What is the average patient waiting time?
- How many patients were admitted?
- How many patients were not admitted?
- What percentage of patients were seen on time?
- How are patients distributed by gender?
- Which age groups visit the Emergency Room most frequently?
- Which departments receive the most referrals?
- How does patient attendance status vary?
- What is the overall patient satisfaction level?

## 🔄 Project Workflow

### 1. Data Extraction

Raw Emergency Room data was imported into Excel and prepared for analysis.

### 2. Data Cleaning & Transformation

Power Query was used to:

- Clean raw data
- Handle data types
- Transform columns
- Prepare data for analysis
- Create analysis-ready datasets

### 3. Data Modeling

Power Pivot was used to create the analytical data model and establish relationships between relevant tables.

### 4. DAX Calculations

DAX measures were created to calculate important healthcare KPIs and analytical metrics.

### 5. Pivot Tables

Pivot Tables were created to summarize Emergency Room performance across different dimensions.

### 6. Dashboard Development

Interactive charts, KPI cards, filters, and visualizations were combined into an Excel dashboard.

The dashboard provides insights into:
